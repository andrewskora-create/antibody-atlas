Local batch analysis

Test your own substitutions or paste full candidate sequences. Each candidate is compared with the original you analyzed above. Sequence positions below are 1-based positions in the pasted input, not IMGT or Kabat numbers.

Syntax: H:N35Q or L:M20L. Comma-separate mutations in one candidate. First compare single substitutions; combinations may interact and need their own measurements.

Paste complete variable-domain sequences using standard one-letter amino acids. Use an empty VL field only when the original has no VL. Candidates must have the same chains and lengths as the original; this comparison supports substitutions only.

Optional models may take longer. Structural differences require a separate fold for each candidate. PROPERMAB uses a fold for each candidate, so selecting it also enables structure analysis. An unavailable model stays unassessed. No composite score or automatic variant rank is assigned.
